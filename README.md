# HopeRise Foundation NGO Website

## Overview
HopeRise Foundation is an NGO website that supports education, healthcare, and community development programs. It allows users to learn about the organization, explore campaigns, donate, and volunteer.

## Features
- Home Page
- About Us
- Campaigns & Projects
- Success Stories
- News & Events
- Donation Section
- Contact Us
- Admin Dashboard

## Admin Functions
- Manage Homepage Content
- Manage Slider Images
- Manage Vision & Mission
- Manage Impact Statistics

## Purpose
To help NGOs showcase their work, raise awareness, and connect with donors and volunteers.
